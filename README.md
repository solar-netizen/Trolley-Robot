# Trolley Robot Project

## Idea
  - A wheeled robot that, when commanded, can lift up a trolley (1-2kg simulation load for the miniature prototype).
  - The robot follows the operator while keeping a distance.
  - The operator can tell the robot to ascend/descend the load.

## Goals
### Create a functioning prototype of the Trolley Robot within a 8-week time frame.
  - The robot should:
      - Follow an IR Transmitter while keeping a distance.
      - Avoid driving into obstacles such as walls and people.
      - Be able to carry 1-2kg of external downwards load.
      - Lift a load 5-10 cm
